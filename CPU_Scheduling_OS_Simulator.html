Scheduling Algorithms Guide

Quick reference for the policies available in this simulator.

FCFS Non-preemptive

Processes run in the exact order they arrive. Simple and fair by arrival time.

  • No starvation
  • Suffer from convoy effect
  • High average waiting time for mixed workloads

SJF Non-preemptive

Always picks the ready process with the shortest burst time.

  • Optimal average waiting time (when BT known)
  • Can starve long jobs
  • Needs accurate burst estimates

SRTF Preemptive

Preemptive version of SJF. Switches whenever a shorter job arrives.

  • Best average waiting time among preemptive policies
  • More context switches
  • Still needs burst-time knowledge

Priority (NP) Non-preemptive

Selects the highest-priority ready process (lower number = higher priority).

  • Important jobs can be preferred
  • Low-priority processes may starve
  • Aging can be added to fix starvation

Priority (P) Preemptive

Preempts the running process if a higher-priority process arrives.

  • Better response for high-priority jobs
  • Higher overhead
  • Starvation still possible without aging

Round Robin Preemptive

Each process gets a fixed time quantum in cyclic order.

  • Excellent response time & fairness
  • Performance depends heavily on quantum size
  • Ideal for time-sharing systems
